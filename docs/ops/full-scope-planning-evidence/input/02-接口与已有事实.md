# 合成业务原始材料：接口与已有事实

输入条目含 source_path、取得时间、媒体类型与原始字节摘要。允许一个来源出现多个版本。标识不能只靠标题：不同文件同名仍是不同来源。

现有工具仅把 Markdown 放进目录，能保留文件，尚无导入恢复、索引查询或出处跳转证明。一次手工打开三个文件说明这三个文件在当时可读，不证明当前整个产品交付。

存储与查询的共同约束为 source_path 和起止行。行号来自保存的原文版本；换版本不能继续引用旧行号而不说明版本。CSV 按原始行定位；网页摘录定位已取得正文，不保证远端网页今后保持同样内容。

本次采用先安排全部当前功能、实施先做来源记录和导入，再做查询。维护产品定义允许直接保存，无须为每项需求创建 Runtime Task。后续正式批次、局部修复、探索是分别提出的请求。
