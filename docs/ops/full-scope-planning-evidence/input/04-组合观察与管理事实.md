# 受限合成输入：组合观察与管理事实

这是人为区分输入的合成设定，非真实运行日志，也不是宿主复现。报告只能评价明确声明的合成对象与样本，不声称真实产品通过。

设定对象为 `组合观察-synthetic-v1`。固定三份已保存原文中，一份 Markdown 有新旧两个版本，一份同名不同路径 Markdown，一份 CSV。直接集成观察记录：原始字节仍可读取；丢弃试验索引后从这三份材料重建；约定关键词找到对应版本，点击位置对应原文行。只观察这些对象、版本与操作，不能扩大为一万条、所有格式或完整产品验收。没有逐个子需求报告，这份直接组合材料仍可用于父需求的固定样本范围。

另一个父能力的组合记录：只观察一个关键词命中并打开原文；资料类型筛选、无结果与一万条使用感受没有观察。已知局部事实保留，余下不是已知失败，不能为了显示进度判成部分满足。

正式增量轮同时区分：UTF-8 BOM 是已采纳新增当前义务；CSV 的行号应指原始行是已有位置约定的细化，不另建同义需求；跨设备同步仍只是未来增强。BOM 影响导入父能力的当前义务，若父对账暂缓或保存冲突，需明确新未核对范围，原固定样本报告不自动扩张或作废。

Runtime 管理输入应来自真实正常操作：局部处理 Task 可以按本合成处置暂停；受限探索 Task 可在未执行步骤仍保留时关闭。Task 生命周期分别据实时 Runtime 读取，与产品交付分开。两 Task 都可关联共用出处范围并保留不同角色；同一 Task 的重复覆盖或冲突来源不能覆盖另一条可信匹配。未确认历史身份保持 null。
