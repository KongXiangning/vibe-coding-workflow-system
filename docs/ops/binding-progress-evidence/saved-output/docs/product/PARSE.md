## [REQ-PARSE] 固定格式文本解析
### 需求内容
接受头为id,value的无引号文本；输出逐行id/value数组；缺失字段指出行号。
### 范围边界
不要求浏览器上传、网络传输或批次历史。
### 验收要求
两个合法记录保留值；缺失value的第二行明确报row 2。
