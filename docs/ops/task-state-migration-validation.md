## 实现与执行边界

新增独立 `task-state-migration.js`，提供 plan／apply／verify／restore，安装包一并交付。
普通 install、upgrade、close-task 不调用此工具。迁移不经过旧内核，不重放业务实施，
不改变 Git index。详细规则见 [迁移工具说明](../../runtime/vnext/support/TASK_STATE_MIGRATION.md)。

旧 reducer 的当前结果转换为每 Task 一份记录及项目状态。保留原任务身份、范围正文、
步骤／执行关联、审查与开放发现、明确的最终遗留清单、实际父子关系和当前焦点。
未知测试结果不提升为 passed，没有 execution_ref 的旧检查不认证当前执行。
原有两条 UNASSOCIATED_RECORD 仍作为缺口保留。

历史材料导入时间不当作生命周期时间：36 个任务保持创建时间未知，33 个关闭任务保持
关闭时间未知；与 TraceLens 原时间读取逻辑逐任务比较，51 项一致。16 份被 PRODUCT
或父子关系明确引用的计划标记 retained；回归实际验证后续普通 prepare 不删除已绑定候选。
旧返回检查点保留历史说明，未伪造新格式下可自动续接的检查点。

软件只在副本覆盖为源码候选，未将同为 0.24.20 的工作区代码冒充已发布升级。工具在
构建时固定五个原生模块的 SHA，安装后检查配套；未增加第六个日常读取依赖。
本轮没有更改 TraceLens 源码。
