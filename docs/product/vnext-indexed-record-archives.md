# vNext：带索引的无损记录归档

实施基线：813d3146561c974c1437fc4d116144dc800bc1ad。范围是 Runtime 记录的物理存储，
不是新的任务状态机、reducer 或开发准入。Node 内置模块运行；Bun 仅用于源码构建和测试。

## 有界实施设计

- 统一逻辑路径读取、枚举、存在性、无覆盖保留和严格幂等追加。旧 ref、事件原字节、
  payload 摘要、CAS 摘要、size、parents 和编号不变；不同运行/失败/中间状态均保留。
- 新事实继续追加 loose。显式 create 只复制已完整发布的不可变文件，验证后激活归档，
  不回收源文件。首期不实现 Git backing，也不改已有捕获内容或为节省空间重写事件。
- 候选只含 events、attachments、evidence-objects、task-labels 及 legacy 的 baseline/current。
  task-view(s)、CURRENT_TASK 和所有 display-* 恢复原件都排除；旧句柄仍可向 capture inode 写入。
- 独立压缩块上限 64 KiB。每段原始块数据、索引和条目数均设上限，单大对象可以跨段；
  按一个引用的一页只读取其索引/所需块，不解压整个包。格式版本、路径边界、偏移、长度、
  块哈希和原始文件哈希均校验。范围读取与显式完整校验分开说明。轻量 manifest 路由到
  相交的索引分片；不为单页加载所有索引。跨归档的路由元数据与全量枚举仍随历史增长。
  v1 的整个 catalog 元数据上限16MiB、归档数4096；create 在激活前核对加入新包后的
  总量，超限保留原 loose，拒绝发布，不将原本可读的存储变为不可读。
- 归档的 manifest、index 和 pack 全部在 records/archives 下，内容寻址名称绑定索引。
  临时目录完整写入、fsync、校验后同文件系统 rename 一次激活。正常读取不依赖本地数据库；
  缺失、损坏、不支持的格式如实报告，不能静默退化为没有记录。
- 写入保留、激活及回收共用短时存储互斥协议，防止“检查不存在→归档移走→重用原ID”的竞态。
  不按文件年龄判断安全，也不按任务关闭推断停止追加。中断不使半个包可见；繁忙/恢复失败
  只是此次管理操作失败，不能成为开发门禁。
- 只有独立显式 quarantine 在归档逐字节核验、原 loose 再校验后移动原件到可恢复隔离区，
  只做可恢复移动。后续独立显式 reclaim 再次完整核验后才清除匹配的重复 loose 表示；
  原字节仍由归档保存，restore 是正常恢复接口，可还原原路径；冲突拒绝覆盖，重复调用幂等。实际业务项目整理
  必须另获授权。安装、升级、task close 和 Git commit 都不自动执行归档或回收。

## 兼容范围与验证

assistance 的 read/find/context、record/snapshot 和 task 的事件枚举、baseline、编号保留
使用统一逻辑存储。任务状态仍按完整事件历史执行现有 reducer；归档不承诺有界全量重放。
find/task-status/context 在单次同步查询内复用已验证 catalog/index 结构，结束即释放，
不持久缓存任务状态。每次复用核对已加载归档目录/文件身份，写入使上下文失效；loose
冲突与选中块校验不省略。结构遍历只需每次查询一次，但保守的签名检查仍随查询次数和
已加载 backing 文件数增长，不承诺任意多包场景的总成本线性。
原生产品资料 SourceRef 和 file-context 的精确读取支持旧路径；外部直接文件系统读取者和
旧版 Runtime 应保留 loose，或显式 restore 后使用。目录搜索的兼容边界由实际实现说明。

Git checkpoint 选择整个必要的 archive manifest/index/pack，按逻辑路径检查类型化引用，
并从实际 index/commit 验证内容。已授权 quarantine 的原 loose 删除须与可验证 backing
共同进入精确计划；缺失的普通事实仍报错。业务路径范围、派生文件忽略、恢复原件和
无提交SHA递归的约定不变。安装清单加入支持模块；升级保留 records，不迁移记录。

验证包括：旧ref字节一致、完整状态/编号/幂等不变、archive/loose冲突、损坏/缺索引/包、
路径与解压上限、中断/并发、分页实际读取量、Git index/commit/离线clone恢复，以及真实
Lawagent与TermLink提交快照的隔离副本。原样本目录哈希前后相同；不执行项目脚本。
工作树文件数/字节和隔离区备份成本分别报告；不把它们称为Git历史或整磁盘节省。

## 不扩展

不清理业务项目、不重写Git历史、不推送/合并/发布、不实现TraceLens功能、不引入第二
套任务流程、不声称所有宿主和未来情况都验证通过。具体结果记录在配套运维验证文档。
